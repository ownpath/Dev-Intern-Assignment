# Checkout Discount Debugging Assignment

This repository contains a small checkout calculation bug from an e-commerce app.

Your job is to investigate the reported issue, make a focused fix, add useful tests, and open a pull request.

## Setup

No third-party packages are required.

```bash
npm test
```

One public test is expected to fail in the starter repository.

## Start here

1. Read [`ISSUE.md`](./ISSUE.md).
2. Run the tests.
3. Inspect the relevant source, tests, fixtures, and repository documents.
4. Reconcile the evidence before choosing a fix.
5. Fix the issue with a small change.
6. Add or improve tests if your investigation finds a gap.
7. Commit useful checkpoints; commit count itself is not scored.
8. Complete [`DECISIONS.md`](./DECISIONS.md) yourself.
9. Open the pull request manually, into `main` on your own fork.

Fork this repository first, and keep your fork public. See "Where to submit" and
"Naming" in [`TASK.md`](./TASK.md) for submission guidance.

You may use AI tools while investigating or coding. Treat suggestions as working
hypotheses: you are responsible for checking their scope and verifying them against
the repository evidence before changing code.
